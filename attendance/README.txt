XAMPP SETUP
1. Copy this "attendance" folder into C:\xampp\htdocs\
2. Open XAMPP Control Panel -> Start Apache and MySQL
3. Browse to http://localhost/attendance/  (it runs setup automatically the first time)
4. Log in: admin/admin123, teacher/teacher123, student/student123 (change these)
5. Delete install.php afterward.
Camera works on http://localhost. For phones on your network you need HTTPS.

ACSS DATA
Your ACSS workbook data (acss_data.json) is imported automatically during first setup.
Already installed? Log in as admin, then open http://localhost/attendance/import_acss.php (safe to re-run).
